# CTA Skill

Paket keterampilan untuk merancang, mengevaluasi, dan memperbaiki Call to Action (CTA) atau ajakan bertindak. Bersifat umum dan tidak terikat pada merek, kreator, kanal, perusahaan, produk, atau platform tertentu.

## Isi paket
- `SKILL.md`: instruksi utama.
- `references/`: jenis CTA, pola penulisan, adaptasi konteks, perjalanan audiens, penilaian mutu, dan etika.
- `examples/`: contoh CTA berdasarkan tujuan.
- `tests/`: kasus uji.

## Cara menggunakan
1. Muat folder ini pada lingkungan agen AI yang mendukung format Agent Skills.
2. Pastikan `SKILL.md` berada di folder utama.
3. Gunakan untuk membuat, memperbaiki, menganalisis, mencocokkan, membuat variasi, atau menyusun rangkaian CTA.

## Catatan
Paket ini berisi instruksi dan bahan kerja, bukan model AI atau aplikasi mandiri. Skill tidak menjamin jumlah klik, penjualan, pendaftaran, atau tingkat konversi tertentu.
