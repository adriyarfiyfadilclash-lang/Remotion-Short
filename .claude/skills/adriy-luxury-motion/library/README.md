# ADRIY Luxury Motion — Final Project

Proyek integrasi tahap akhir untuk gaya **Luxury Motion** di Remotion.

## Yang digabungkan
- Fondasi skill dan token visual.
- Animation Library.
- Transition Library.
- Typography Library.
- Lighting & Effects Library.
- Contoh film produk 15 detik, 1920×1080, 30 fps.

## Menjalankan
1. Ekstrak ZIP.
2. Buka folder proyek di terminal.
3. Jalankan `npm install`.
4. Jalankan `npm run start` untuk membuka Remotion Studio.
5. Pilih komposisi `LuxuryProductFilm`.
6. Untuk render: `npm run render`.

## Catatan penting
Demo menggunakan botol parfum bergaya ilustrasi CSS sebagai objek sementara. Ini bukan model 3D fotorealistis. Ganti komponen `ProductBottle` di `src/LuxuryProductFilm.tsx` dengan foto produk transparan atau render 3D milikmu untuk hasil iklan yang lebih realistis.

Paket ini mengintegrasikan komponen yang dibangun pada tahap-tahap sebelumnya. Tetap lakukan pemeriksaan render di lingkungan proyekmu sebelum dipakai untuk produksi. Font contoh memakai Georgia dan Arial agar tidak memerlukan pemasangan font tambahan.
