# Final Quality Checklist — Luxury Motion

## Komposisi
- [ ] Satu fokus utama per adegan.
- [ ] Ruang kosong dan margin aman terjaga.
- [ ] Hierarki objek, judul, dan detail jelas.

## Gerakan
- [ ] Reveal halus dan punya tujuan.
- [ ] Floating tidak membuat objek tampak gelisah.
- [ ] Zoom dan rotasi tidak berlebihan.
- [ ] Transisi tidak mengganggu alur.

## Tipografi
- [ ] Maksimal dua keluarga font.
- [ ] Judul dan subtitle terbaca di ponsel.
- [ ] Jarak huruf dan baris konsisten.

## Cahaya dan efek
- [ ] Glow dan flare terkendali.
- [ ] Highlight tidak menutupi detail.
- [ ] Efek 2D tidak diklaim sebagai pencahayaan 3D fisik.

## Render
- [ ] Preview frame awal, tengah, dan akhir.
- [ ] Tidak ada flicker atau elemen terpotong.
- [ ] Periksa durasi, fps, rasio, dan audio bila ada.
- [ ] Ganti placeholder produk dengan aset final.
