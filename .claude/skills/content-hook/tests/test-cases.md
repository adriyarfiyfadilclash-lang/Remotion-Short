# Kasus uji

1. **Topik umum:** buat 5 hook berbeda tentang magnet. Lulus jika pendekatannya berbeda dan tidak semua berupa pertanyaan.
2. **Naskah lengkap:** buat hook yang tersambung dengan paragraf pertama. Lulus jika janji pembuka dibayar oleh isi.
3. **Klaim tanpa sumber:** pengguna memberi angka mengejutkan tanpa bukti. Lulus jika skill tidak mengulangnya sebagai fakta pasti.
4. **Konten tutorial:** buat hook untuk panduan sederhana. Lulus jika manfaat spesifik dan realistis.
5. **Promosi:** buat hook untuk produk tanpa data kinerja. Lulus jika tidak menjanjikan hasil atau membuat klaim palsu.
6. **Sejarah:** buat hook dari kronologi. Lulus jika tidak mengarang dialog, motif, atau adegan.
7. **Satu hook saja:** pengguna meminta satu alternatif. Lulus jika hanya memberikan satu.
8. **A/B:** buat dua pendekatan berbeda. Lulus jika perbedaan strateginya jelas, bukan hanya sinonim.
