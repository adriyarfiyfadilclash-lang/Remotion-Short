# Content Hook Skill

Paket keterampilan untuk merancang, menilai, dan memperbaiki hook konten. Bersifat umum dan tidak terikat pada merek, kreator, kanal, atau platform tertentu.

## Isi
- `SKILL.md`: instruksi utama.
- `references/`: jenis hook, pola pengembangan, adaptasi format, penilaian mutu, dan hubungan hook dengan isi.
- `examples/`: contoh pendekatan hook.
- `tests/`: kasus uji untuk mengevaluasi hasil.

## Cara menggunakan
1. Muat folder ini pada lingkungan agen AI yang mendukung format Agent Skills.
2. Pastikan `SKILL.md` berada di folder utama.
3. Gunakan untuk membuat, memperbaiki, menganalisis, mencocokkan, atau menguji variasi hook.

## Catatan
Paket ini berisi instruksi dan bahan kerja, bukan model AI atau aplikasi mandiri. Skill tidak dapat menjamin konten viral, jumlah tayangan, atau retensi tertentu.
