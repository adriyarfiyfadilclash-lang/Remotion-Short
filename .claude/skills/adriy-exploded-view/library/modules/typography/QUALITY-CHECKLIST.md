# Daftar Pemeriksaan Kualitas

- [ ] Semua tujuh komponen diekspor melalui `src/index.ts`.
- [ ] Teks terbaca pada resolusi akhir.
- [ ] Nomor komponen sesuai dengan urutan bagian.
- [ ] Garis penunjuk menyentuh bagian yang benar.
- [ ] Garis ukuran dan label dimensi tidak bertabrakan.
- [ ] Keterangan teknis tidak menutupi objek.
- [ ] Font tersedia secara lokal jika render tanpa jaringan diperlukan.
- [ ] Animasi reveal tetap deterministik.
- [ ] Jalankan pemeriksaan TypeScript dan uji render sebelum produksi.
