# Daftar Pemeriksaan Kualitas

- [ ] Semua tujuh komponen diekspor melalui `src/index.ts`.
- [ ] Anak langsung `ExplodedAssembly` menerima properti `progress`.
- [ ] Posisi awal komponen membentuk rakitan yang benar.
- [ ] Posisi akhir komponen terurai tidak saling bertabrakan.
- [ ] Jeda animasi membuat urutan pemisahan mudah dipahami.
- [ ] Komponen tidak keluar dari bingkai.
- [ ] Perakitan kembali mengembalikan posisi dan rotasi awal.
- [ ] Tidak ada penggunaan gerakan acak yang tidak deterministik.
- [ ] Jalankan pemeriksaan TypeScript dan uji render sebelum produksi.
