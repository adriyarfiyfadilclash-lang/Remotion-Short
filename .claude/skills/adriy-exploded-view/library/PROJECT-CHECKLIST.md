# Pemeriksaan Proyek Final

## Struktur
- [ ] Enam modul tersedia di folder `modules/`.
- [ ] Ekspor gabungan tersedia di `src/index.ts`.
- [ ] Komposisi terdaftar di `src/Root.tsx`.
- [ ] Contoh final tersedia di `src/ExplodedViewFinalShowcase.tsx`.

## Instalasi dan pemeriksaan
- [ ] Jalankan `npm install`.
- [ ] Jalankan `npm run check`.
- [ ] Buka `npm run studio`.
- [ ] Periksa komposisi pada awal, tengah, dan akhir.
- [ ] Jalankan `npm run render`.

## Pemeriksaan visual
- [ ] Semua komponen tetap di dalam bingkai.
- [ ] Tidak ada tabrakan geometri yang mengganggu.
- [ ] Label dan garis penunjuk terbaca.
- [ ] Kamera tidak kehilangan objek saat bergerak.
- [ ] Pencahayaan tidak membuat material kehilangan detail.
- [ ] Efek tidak menutupi informasi utama.

## Produksi
- [ ] Ganti geometri contoh dengan model objek yang sesuai.
- [ ] Cocokkan durasi animasi dengan narasi.
- [ ] Tambahkan musik/suara secara terpisah sesuai kebutuhan.
- [ ] Simpan hasil render dan versi proyek.
