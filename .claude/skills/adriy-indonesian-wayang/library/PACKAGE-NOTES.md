# Catatan Paket

- Target Remotion: 4.x
- React: 18.x
- Bahasa sumber: TypeScript + TSX
- Ukuran komposisi utama: 1920×1080
- Laju bingkai: 30 fps
- Durasi komposisi utama: 930 frame / 31 detik
- Tidak ada berkas audio atau font eksternal yang dibundel.
- Beberapa efek memakai CSS/SVG; hasil akhir dapat berbeda antarversi Chromium/Remotion.
- Jalankan pemeriksaan dependensi dan render di perangkat pengembangan sebelum produksi.
