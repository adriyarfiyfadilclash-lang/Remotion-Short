# Daftar Pemeriksaan Kualitas

- [ ] Semua tujuh komponen diekspor dari `src/index.ts`.
- [ ] Setiap id atom pada daftar ikatan ditemukan di daftar atom.
- [ ] Ikatan tidak terputus dari pusat atom.
- [ ] Radius atom dan ketebalan ikatan terbaca pada kamera akhir.
- [ ] Transparansi membran tidak menutupi inti secara berlebihan.
- [ ] Posisi inti dan organel tidak saling bertabrakan secara tidak sengaja.
- [ ] Heliks DNA memiliki rel dan anak tangga yang terlihat.
- [ ] Warna memiliki legenda atau penjelasan bila diperlukan.
- [ ] Skala dan geometri ilmiah dicocokkan dengan sumber jika klaim akurasi dibuat.
- [ ] Jalankan pemeriksaan TypeScript dan uji render sebelum produksi.
