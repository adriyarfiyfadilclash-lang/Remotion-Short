# Daftar Pemeriksaan Kualitas

- [ ] Semua tujuh komponen diekspor dari `src/index.ts`.
- [ ] Animasi berbasis bingkai dan deterministik.
- [ ] Orbit tidak membuat objek keluar dari bingkai.
- [ ] Gelombang memiliki jumlah segmen dan amplitudo yang sesuai.
- [ ] Aliran partikel tidak terlalu padat.
- [ ] Getaran molekul tidak berlebihan.
- [ ] Denyut sel terlihat halus dan tidak mengganggu.
- [ ] Pertumbuhan dimulai dan berakhir pada skala yang tepat.
- [ ] Contoh diberi keterangan sebagai ilustrasi konseptual.
- [ ] Jalankan pemeriksaan TypeScript dan uji render sebelum produksi.
