# Kasus uji Channel Skill

1. **Profil kosong:** skill memulai dengan menanyakan nama kanal dan mengumpulkan rasio serta durasi secara bertahap.
2. **Sebagian profil tersedia:** pengguna sudah menyebut nama kanal dan rasio. Skill hanya menanyakan durasi atau informasi penting yang belum tersedia.
3. **Permintaan hook saja:** skill membuat hook sesuai profil tanpa memaksakan naskah penuh dan CTA.
4. **Paket lengkap:** hook, naskah, dan CTA saling selaras serta sesuai durasi.
5. **Rasio:** pengguna memilih 9:16. Skill menyebutnya sebagai arahan visual dan tidak mengubah isi narasi secara keliru.
6. **Durasi:** pengguna meminta 60 detik. Skill memperkirakan jumlah kata dan memberi catatan bahwa durasi aktual perlu diuji dengan pembacaan.
7. **Nama kanal:** nama kanal tidak dimasukkan secara berulang atau dipaksakan dalam narasi.
8. **Niche belum diketahui:** skill bertanya atau menyatakan asumsi, bukan mengarang bidang kanal.
