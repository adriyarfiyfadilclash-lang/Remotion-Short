# Channel Skill

Skill umum untuk membantu pengguna mengelola arah konten kanal dan menghasilkan hook, naskah, serta CTA yang sesuai dengan identitas dan kebutuhan kanal.

## Isi paket
- `SKILL.md`: instruksi utama.
- `references/`: panduan pengenalan kanal, alur konten, durasi, serta hubungan hook–naskah–CTA.
- `templates/`: templat profil kanal.
- `tests/`: kasus uji.

## Cara menggunakan
1. Muat folder ini pada lingkungan agen AI yang mendukung format Agent Skills.
2. Pastikan `SKILL.md` berada di folder utama.
3. Mulai dengan `SETUP CHANNEL` untuk mengumpulkan profil kanal.
4. Gunakan mode `HOOK`, `SCRIPT`, `CTA`, atau `PAKET LENGKAP` untuk pekerjaan berikutnya.

## Catatan
Paket ini adalah instruksi skill, bukan aplikasi atau model AI mandiri. Informasi profil kanal digunakan sebagai konteks kerja oleh lingkungan yang memuat skill ini.
