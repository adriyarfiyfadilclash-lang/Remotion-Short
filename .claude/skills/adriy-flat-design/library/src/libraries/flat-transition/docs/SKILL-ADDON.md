# Skill Add-on — Flat Transition

Gunakan transisi sebagai penghubung antaradegan, bukan hiasan di setiap potongan.
- Pilih `FlatWipe` untuk perpindahan tegas dan grafis.
- Pilih `FlatCircleIris` atau `FlatShapeReveal` untuk membuka fokus visual.
- Pilih `FlatSplitReveal` untuk infografik dan komposisi geometris.
- Pilih `FlatSlideSwap` untuk mengganti dua panel/adegan.
- Pilih `FlatZoomCut` untuk penekanan atau perubahan skala.

Jaga durasi umum 12–30 bingkai pada 30 fps. Sesuaikan dengan tempo narasi dan musik.
Pastikan warna transisi kontras dengan kedua adegan dan hindari transisi panjang pada informasi padat.
