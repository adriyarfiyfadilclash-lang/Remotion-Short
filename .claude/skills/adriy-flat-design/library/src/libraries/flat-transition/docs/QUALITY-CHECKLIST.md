# Daftar Pemeriksaan Kualitas
- [ ] Semua transisi punya durasi yang masuk akal dan tidak menutupi informasi penting.
- [ ] Warna bidang transisi konsisten dengan palet video.
- [ ] Arah gerak sesuai arah baca dan komposisi.
- [ ] Tidak ada kilatan warna yang terlalu terang atau cepat.
- [ ] Adegan awal dan akhir tidak terpotong secara tidak sengaja.
- [ ] Periksa hasil di Remotion Studio pada resolusi akhir.
- [ ] Render cuplikan pendek sebelum render video penuh.
