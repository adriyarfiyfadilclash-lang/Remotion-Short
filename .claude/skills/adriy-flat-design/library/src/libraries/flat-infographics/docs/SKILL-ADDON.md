# Skill Add-on — Flat Infographics

Gunakan infografik untuk mengubah data dan proses menjadi visual yang cepat dipahami.
- Diagram batang: membandingkan nilai antar kategori.
- Diagram donat: menunjukkan komposisi bagian terhadap total.
- Garis waktu: menjelaskan urutan kejadian.
- Langkah proses: menunjukkan tahapan dan posisi saat ini.
- Kartu perbandingan: memperlihatkan perbedaan dua pilihan.
- Kartu statistik: menonjolkan angka utama.

Aturan:
1. Gunakan data yang benar dan satuan yang jelas.
2. Tampilkan judul yang menjelaskan pesan, bukan sekadar nama diagram.
3. Jangan memotong skala atau menyembunyikan konteks yang dapat menyesatkan.
4. Batasi warna agar kategori mudah dibedakan.
5. Beri waktu baca sebelum berpindah ke adegan berikutnya.
