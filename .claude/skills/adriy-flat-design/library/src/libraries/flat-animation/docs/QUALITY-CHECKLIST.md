# Flat Animation — Quality Checklist

- [ ] Gerakan mudah dibaca dan sesuai fungsi elemen.
- [ ] Tidak ada elemen yang terpotong tanpa sengaja.
- [ ] Kecepatan dan jarak gerak konsisten.
- [ ] Efek bounce tidak berlebihan.
- [ ] Stagger memiliki urutan yang jelas.
- [ ] Warna dan kontras tetap terbaca.
- [ ] Ilustrasi tidak berubah bentuk saat dianimasikan.
- [ ] Preview dan render akhir sudah diperiksa.
