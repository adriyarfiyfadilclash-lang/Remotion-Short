# Daftar Pemeriksaan Kualitas
- [ ] Efek memiliki tujuan visual yang jelas.
- [ ] Intensitas gerak tidak membuat penonton tidak nyaman.
- [ ] Getaran hanya digunakan singkat dan sesuai konteks.
- [ ] Efek cahaya tidak mengurangi keterbacaan.
- [ ] Lapisan parallax memiliki urutan kedalaman yang benar.
- [ ] Tekstur tidak menutupi detail penting.
- [ ] Periksa transisi awal/akhir efek pada bingkai batas.
- [ ] Tinjau hasil pada resolusi akhir di Remotion Studio.
