# Daftar Pemeriksaan Kualitas
- [ ] Bentuk mendukung pesan, bukan sekadar dekorasi.
- [ ] Ikon mudah dikenali pada ukuran layar ponsel.
- [ ] Gaya garis dan sudut konsisten.
- [ ] Palet warna terbatas dan kontrasnya cukup.
- [ ] Bentuk tidak menutupi teks atau objek penting.
- [ ] Gerakan masuk tidak terlalu memantul atau mengganggu.
- [ ] Periksa pada resolusi dan ukuran keluaran akhir.
