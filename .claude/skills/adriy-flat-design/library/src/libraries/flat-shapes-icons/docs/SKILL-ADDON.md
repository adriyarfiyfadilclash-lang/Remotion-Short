# Skill Add-on — Flat Shapes & Icons

Gunakan bentuk geometris untuk membantu menjelaskan ide, mengarahkan perhatian, dan membangun komposisi.
- Lingkaran: fokus, titik, hubungan, atau penekanan.
- Persegi: informasi, panel, dan struktur.
- Segitiga/panah: arah, alur, atau perubahan.
- Bentuk organik: aksen visual, bukan pengganti informasi.
- Ikon: pilih simbol sederhana yang maknanya langsung dikenali.

Jaga konsistensi ketebalan garis, sudut, ukuran, dan palet warna. Hindari menumpuk terlalu banyak bentuk dalam satu adegan.
