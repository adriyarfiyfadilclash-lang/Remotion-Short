# Package Notes

- Aset dibuat sebagai SVG React; tidak membutuhkan gambar eksternal.
- Gunakan setiap komponen di dalam kontainer dengan lebar dan tinggi yang ditentukan.
- Properti `x` dan `y` menggeser isi SVG pada koordinat internal.
- `scale` mengubah ukuran geometri aset.
- `color` mengatur siluet, `accentColor` mengatur garis ornamen.
- Aset bersifat ilustrasi generik; bukan model presisi sejarah/arkeologi.
