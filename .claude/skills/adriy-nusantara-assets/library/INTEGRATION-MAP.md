Impor:
```tsx
import {
  GununganAsset, KeratonAsset, CandiAsset,
  NusantaraShipAsset, TraditionalWeaponAsset,

```

Komponen dapat diletakkan di dalam `AbsoluteFill`, `Sequence`, atau komposisi adegan. Untuk gaya wayang, tempatkan aset di belakang karakter dan gunakan palet hitam dengan aksen warna hangat.
