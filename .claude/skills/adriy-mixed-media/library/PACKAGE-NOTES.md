# Package Notes

Peer dependencies:
- `react`: gunakan versi yang kompatibel dengan proyek Remotion.
- `remotion`: gunakan versi yang sama dengan paket Remotion lain pada proyek induk.

Tidak mengunci versi karena paket ini dimaksudkan untuk diintegrasikan ke proyek pengguna. Contoh tidak menyertakan instalasi otomatis atau lockfile.
