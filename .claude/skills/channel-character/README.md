# Channel Character Skill

Skill untuk membaca dan memetakan karakter kreatif sebuah kanal dari contoh video, naskah, transkrip, caption, atau materi lain yang diberikan pengguna.

## Isi paket
- `SKILL.md` — instruksi utama dan mode operasi.
- `references/profile-template.md` — templat profil karakter kanal.
- `references/analysis-framework.md` — kerangka analisis bukti dan pola.
- `references/character-fit-checklist.md` — pemeriksaan kesesuaian hasil.
- `references/sample-prompts.md` — contoh permintaan.
- `references/workflow.md` — alur kerja operasional.

## Cara menggunakan
Muat folder `Channel-Character-Skill` ke lingkungan AI yang mendukung format Agent Skills. Setelah skill tersedia, pengguna dapat meminta analisis dengan mengirim contoh materi kanal.

Contoh:
"Analisis naskah dan transkrip berikut, lalu buat profil karakter kanal yang bisa dipakai untuk semua konten berikutnya."

## Catatan
Skill ini adalah paket instruksi dan referensi. Skill tidak menjadi model AI mandiri dan tidak otomatis terpasang pada semua aplikasi. Kemampuan membaca video bergantung pada apakah lingkungan pemuat skill dapat mengakses video atau transkripnya.
