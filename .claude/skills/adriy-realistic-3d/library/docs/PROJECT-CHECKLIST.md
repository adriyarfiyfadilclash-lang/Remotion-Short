# Final Project Quality Checklist

## Struktur
- [ ] Enam modul ada di `src/modules`.
- [ ] Semua barrel ekspor modul tersedia.
- [ ] Enam showcase terdaftar pada `src/Root.tsx`.
- [ ] Semua impor lokal mengarah ke folder modul yang benar.

## Lingkungan
- [ ] `npm install` berhasil.
- [ ] `npm run typecheck` berhasil.
- [ ] Remotion Studio dapat membuka keenam komposisi.
- [ ] Keenam komposisi dapat dirender tanpa error.

## Visual
- [ ] Kamera tidak saling menimpa dalam satu adegan.
- [ ] Teks 3D menggunakan font lokal yang valid.
- [ ] Material kaca dan logam terlihat sesuai.
- [ ] Bayangan tidak hilang atau terlalu pekat.
- [ ] Partikel tidak membebani render secara berlebihan.
- [ ] Tidak ada kedipan antar-frame.
- [ ] Hasil akhir diperiksa pada resolusi 1920×1080.
