# Remotion-Short

## Video: Cara Kerja Jantung (gaya ADRIY Anatomical 3D)

- Ukuran: 1080×1920 (9:16), 30 fps, durasi 2:35
- Semua teks dan urutan adegan ada di `src/data.json`
- Efek suara dan musik dibuat sendiri (bebas hak cipta) oleh `scripts/buat-sfx.py`
- Model jantung 3D adalah ilustrasi edukasi, bukan model medis
- Sumber fakta: NHLBI (NIH), Cleveland Clinic, Merck Manual

### Render dari HP
1. Buka tab **Actions** di repo ini
2. Pilih **Render Video**, lalu ketuk **Run workflow** dua kali
3. Tunggu tanda hijau, lalu unduh **video** di bagian **Artifacts**
